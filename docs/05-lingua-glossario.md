# Glossário — NormaReview AI

> Wikilink: [[Glossário]] · Sprint 0 — Fundação e Alinhamento

Este glossárioLista termos que precisam de significado compartilhado. Sempre que um termo for usado em issue, PR ou decisão, ele deve ter sentido coerente aqui.

---

## Quadro resumo

| Termo | Conceito |
|---|---|
| Artigo / Manuscripto | Texto acadêmico em revisão. |
| Revisão acadêmica | Análise de problemas de formatação, citação, referências e convenções acadêmicas. |
| Norma ABNT | Padrão/convenção usada como base de verificação. |
| Conformidade | Grau de adequação do documento às verificações aplicadas. |
| Crítico | Problema que pede resolução antes de considerar o documento revisado. |
| Advertência | Problema relevante com possível dependência de contexto. |
| Observação | Ponto de atenção, não erro obrigatório. |
| Rascunho | Versão em andamento do documento. |
| Regras base | Verificações determinísticas mantidas na engine de revisão. |
| Assistência IA | Serviço que sugere mudanças, reformulações ou explicações. |
| Diff | Comparação entre versões de um texto/Manuscripto. |
| Problema de revisão | Item identificado pela análise que pode precisar de ação. |
| Critério de aceitação | Condição que define quando uma tarefa é considerada pronta. |
| Sprint | Ciclo de trabalho com objetivo e entregáveis definidos. |
| Backlog | Lista de trabalho pendente, priorizada e sujeita a refinamento. |
| CEREBRO do projeto | Documento central do projeto. |
| Wikilink | Referência interna entre documentos do projeto. |
| Lean Canvas | Documento de alinhamento com problema, público, proposta e decisão de MVP. |
| Plan Sprint | Documento de plano da sprint com objetivo, entregáveis e critério de prontidão. |
| Contributing | Documento que orienta como abrir issue, PR e contribuir. |
| Arquitetura por Módulos | Documento que define responsabilidade e fronteiras entre módulos. |

---

## Padrão de links internos

- Use [[Wikilink]] com o nome do documento seguido pelo título esperado no CEREBRO.
- Se o documento mudar de nome, atualize também o link e a referência no CEREBRO.
- Evite criar muitos níveis de sublink antes de saber se o documento realmente vai ser mantido.

---

## Exemplos de uso

- Se uma issue fala em “regra crítica”, espera-se que ela se refira a problema com severidade crítica no sentido deste glossário.
- Se um PR menciona “mudança de regras base”, isso deve estar relacionado a [[Arquitetura por Módulos]] e [[Decisões Técnicas]].
- Se alguém pergunta “isso é sugestão ou exigência?”, a resposta deve seguir a separação entre regras base e assistência IA.
- Se o time quer revisar escopo, parte da conversa deve começar pelo [[Lean Canvas do Projeto]] e pelo [[Backlog v1]].
